# AlphaAgent Examples

This directory contains examples demonstrating how to use the AlphaAgent for quantum circuit optimization.

## Running the Examples

```bash
python3 alpha_agent_example.py
```

## What's Included

The example script demonstrates three use cases:

1. **Single Parameter Optimization**: Optimizing a single rotation angle in a quantum gate
2. **Multi-Parameter Optimization**: Optimizing multiple parameters simultaneously
3. **Circuit Evaluation**: Using the agent to evaluate circuit quality metrics

## Requirements

- qsimcirq (with AlphaAgent)
- cirq-core
- numpy
- sympy

All requirements are included when you install qsimcirq.
