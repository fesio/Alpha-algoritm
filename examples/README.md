# qsim Examples

This directory contains beginner-friendly examples to help you get started with qsim.

## Available Examples

### 1. basic_circuit.py
A simple introduction to quantum circuits. This example shows:
- How to create qubits
- How to apply basic quantum gates
- How to simulate and measure results

**Difficulty**: Beginner  
**Run**: `python3 basic_circuit.py`

### 2. bell_state.py
Create and verify a Bell state (maximally entangled quantum state). This example demonstrates:
- Quantum entanglement
- Hadamard and CNOT gates
- Measurement correlations

**Difficulty**: Beginner  
**Run**: `python3 bell_state.py`

### 3. quantum_teleportation.py
Implementation of the quantum teleportation protocol. This example shows:
- Advanced quantum protocols
- Multi-qubit operations
- Classical communication with quantum operations

**Difficulty**: Intermediate  
**Run**: `python3 quantum_teleportation.py`

## Prerequisites

Make sure you have qsimcirq installed:
```bash
pip3 install qsimcirq
```

## Running Examples

To run any example, simply execute:
```bash
python3 <example_name>.py
```

For example:
```bash
python3 basic_circuit.py
```

## Learning Path

We recommend following these examples in order:
1. Start with `basic_circuit.py` to understand the basics
2. Move to `bell_state.py` to learn about entanglement
3. Try `quantum_teleportation.py` for an advanced protocol

## Modifying Examples

Feel free to modify these examples! Some ideas:
- Change the number of qubits
- Add different quantum gates
- Increase the number of measurement repetitions
- Try different initial states
